# 中证500多因子选股策略

基于量价因子的中证500多空策略。包含数据获取、因子计算、因子筛选、IC 检验、分层回测、绩效评估的完整流程，支持季度调仓与交易成本建模。

## 分时段检验与失效归因

| 区间 | 样本期数 | 毛夏普 | 净夏普 | 胜率 | 最大回撤 | 分层单调性 |
|------|----------|--------|--------|------|----------|------------|
| 全样本 | 22期 | 0.38 | 0.28 | 63.6% | -33.23% | 非单调 |
| 训练期 | 14期 | 1.41 | 1.27 | 76.9% | -9.10% | 递增 |
| 验证期 | 8期 | -0.32 | -0.40 | 44.4% | -34.39% | 非单调 |

**失效与尾部风险分析**：
全样本夏普由前期的 0.95 降至 0.28，主要归因于以下两点：
1. **尾部逼空风险**：补算了完整的持有期后，发现在 2025 年第三季度，策略的空头端（评分最低的25%个股）单季暴涨了 38.86%，导致多空组合单季回撤达 -31.63%。这印证了单一反转因子在极端风格轮动（如垃圾股/微盘股炒作）下的脆弱性。
2. **数据严谨性修复**：修复了此前回测中停牌股票未正确估值、以及最后一段持有期漏算的问题。

## 因子筛选过程

原始方案用 5 个因子等权合成。通过逐因子分层检验（基于训练期），仅保留单调性最好的两个因子：

| 因子 | 含义 | 训练期单调性 | 结论 |
|------|------|--------------|------|
| reversal | 20日反转 | 递增 | 保留 |
| ma_ratio | MA5/MA20-1 | 递增 | 保留 |
| volatility | 20日波动率 | 非单调 | 剔除 |
| avg_turn | 20日换手率 | 非单调 | 剔除 |
| EP | 盈利收益率 | 非单调 | 剔除 |

## 因子权重

采用 IC_IR 加权为基准，对 ma_ratio 权重做敏感性测试。夏普在 0.6~0.8 区间稳定，最终取 0.6/0.4，主动避开样本内峰值 0.7，避免过拟合。

## 因子预处理

1. 去极值：3 倍 MAD
2. 标准化：排名百分位，输出 [-0.5, 0.5]
3. 方向统一：按因子方向取反

## 回测严谨性说明

为避免未来函数与虚假收益，代码在以下方面做了严格限制：
1. **严格 T+1 交易**：T 日收盘产生信号，T+1 日以统一交易日历的开盘价成交。
2. **停牌双重处理**：若 T+1 日停牌无法成交，该部分资金留作现金（收益 0）；若买入后停牌，则使用期末前的最后一次有效收盘价进行盯市估值，拒绝凭空抹平亏损。
3. **防缺失剔除**：选股仅依赖当期因子截面，绝不使用 `dropna(future_ret)` 过滤候选池，防止因未来停牌/退市而虚增收益。
4. **严格样本划分**：训练期（14期）与验证期（8期）首尾相接，合起来完全等于全样本（22期），无边界重叠或丢失。

## 测试

```bash
pytest tests/ -v
```

6 个测试，含：
- `test_no_lookahead`：验证因子计算不使用未来数据
- `test_standardize_range`：验证标准化输出在 [-0.5, 0.5]
- `test_sharpe_known_value`：手算算术夏普对比

## 运行方式

```bash
pip install -r requirements.txt
python main.py
python plot_results.py
```

首次运行通过 baostock 拉取数据并缓存到 `data/`，后续直接读缓存。可修改 `main.py` 中的 `RUN_PHASE` 开关（'train'/'valid'/'all'）运行不同时段。

## 尝试过但未采用的方案

**行业中性化**：用 baostock 行业分类（19 个门类），对每个因子减去行业均值。  
结果：在早期回测中毛夏普下降，分层被破坏。原因可能是该策略 alpha 主要来自行业间差异。代码保留在 `industry.py`，开关 `USE_INDUSTRY_NEUTRAL` 默认关闭。

## 已知局限

- 使用当前中证500成分股，存在幸存者偏差。
- 未做行业中性化。
- 回测未包含融券成本与借券可得性限制。
- 验证期遭遇极端的空头逼空行情，样本仅有 8 期，统计显著性较弱。
- 目前仅按季度净值计算最大回撤，可能低估期内波动。

## 后续改进方向

- 用历史成分股消除幸存者偏差。
- 引入风格中性化或波动率目标控制尾部风险。
- 加入动量因子以对冲极端逼空行情。
