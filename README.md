# 中证500多因子选股策略

基于量价因子的中证500多空策略。包含数据获取、因子计算、因子筛选、IC 检验、分层回测、绩效评估的完整流程，支持季度调仓与交易成本建模。

## 分时段检验与风险分析

本结果为固定参数后的分时段检验，不构成独立样本外验证。区间按信号日归属，持有期可能跨越名义分界日期。

| 区间 | 样本期数 | 毛夏普 | 净夏普 | 胜率 | 毛收益最大回撤 | 净收益最大回撤 | 分层单调性 |
|------|----------|--------|--------|------|----------------|----------------|------------|
| 全样本 | 23期 | 0.38 | 0.28 | 63.6% | -33.23% | -34.39% | 非单调 |
| 训练期 | 14期 | 1.41 | 1.27 | 76.9% | -8.15% | -9.10% | 递增 |
| 验证期 | 9期 | -0.32 | -0.40 | 44.4% | -33.23% | -34.39% | 非单调 |

**风险与失效归因**：
1. **口径与公式说明**：旧版（无严格切片、无T+1停牌处理等）毛夏普为 0.95，净夏普为 0.80；在修复底层逻辑及改用算术夏普公式后，新版全样本毛夏普降至 0.38，净夏普降至 0.28。
2. **尾部亏损归因**：补算了完整的持有期后，发现在 2025 年第三季度，多空组合单季毛收益为 -31.63%。排查持仓发现，该季度空头端（评分最低的25%个股）整体大幅上涨（单季涨幅 38.86%）。这属于空头端大幅上涨导致的尾部亏损，致使整体多空策略遭遇重创。

## 因子筛选过程

原始方案用 5 个因子等权合成。在初步探索阶段（注：该探索使用了全样本信息），逐因子分层检验结果如下：

| 因子 | 含义 | 单调性 | 结论 |
|------|------|--------|------|
| reversal | 20日反转 | 递增 | 保留 |
| ma_ratio | MA5/MA20-1 | 递增 | 保留 |
| volatility | 20日波动率 | 非单调 | 剔除 |
| avg_turn | 20日换手率 | 非单调 | 剔除 |
| EP | 盈利收益率 | 非单调 | 剔除 |

*(注：代码当前直接使用基于前期探索确定的固定权重组合，未实现动态 IC_IR 加权计算。)*

## 因子权重

代码当前固定使用 0.4 / 0.6 的权重组合。前期敏感性测试显示，夏普在 0.6~0.8 区间内较为稳定，故选定 0.4/0.6。

## 因子预处理

1. 去极值：3 倍 MAD
2. 标准化：排名百分位，输出 [-0.5, 0.5]
3. 方向统一：按因子方向取反

## 回测逻辑说明

代码在以下方面做了限制，以提高回测的真实性：
1. **T+1 交易**：T 日收盘产生信号，T+1 日以统一交易日历的开盘价成交。
2. **停牌处理**：若 T+1 日停牌无法成交，该部分资金留作现金；若买入后停牌，则使用期末前的最后一次有效收盘价进行盯市估值（若未成交与无有效估值未能完全区分，代码将记录为缺失）。
3. **样本划分**：训练期与验证期通过信号日严格切分，无边界重叠。

## 测试

```bash
pytest tests/ -v
```

6 个测试，含：
- `test_no_lookahead`：验证因子计算不使用未来数据
- `test_standardize_range`：验证标准化输出在 [-0.5, 0.5]
- `test_sharpe_known_value`：手算算术夏普对比

## 运行方式

```bash
pip install -r requirements.txt
python main.py
python plot_results.py
```

首次运行通过 baostock 拉取数据并缓存到 `data/`，后续直接读缓存。可修改 `main.py` 中的 `RUN_PHASE` 开关（'train'/'valid'/'all'）运行不同时段。

## 尝试过但未采用的方案

**行业中性化**：用 baostock 行业分类（19 个门类），对每个因子减去行业均值。  
结果：在早期回测中毛夏普下降，分层被破坏。代码保留在 `industry.py`，开关 `USE_INDUSTRY_NEUTRAL` 默认关闭。

## 已知局限

- 使用当前中证500成分股，存在幸存者偏差。
- 回测未包含融券成本与借券可得性限制。
- 验证期样本较少，统计显著性较弱。
- 仅按季度净值计算最大回撤，可能低估期内波动。
