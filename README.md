# 多因子选股策略（中证500）

基于量价与基本面因子的中证500多空策略，包含数据获取、因子计算、因子检验、合成打分、分层回测与绩效评估的完整流程。

## 回测结果

**回测区间**：2020-01 ~ 2025-10  
**调仓频率**：季度  
**股票池**：中证500成分股（297只）

**交易成本**：双边千2.5

## 因子体系

| 因子 | 含义 | 方向 |
|------|------|------|
| momentum | 20日动量 | 越小越好 |
| volatility | 20日波动率 | 越小越好 |
| avg_turn | 20日平均换手率 | 越小越好 |
| ma_ratio | MA5/MA20 - 1 | 越小越好 |
| EP | 净利润TTM / 收盘价 | 越大越好 |

## 因子预处理

1. 去极值：3倍MAD法
2. 标准化：排名百分位，输出区间 [-0.5, 0.5]
3. 方向统一：按因子在样本内的IC方向取反

## 因子检验

- IC分析：Spearman秩相关，计算IC均值、IC_IR、胜率
- 分层回测：按综合打分分为5组，检验单调性

## 项目结构

```
.
├── config.py           # 全局配置（因子、权重、交易成本）
├── data_loader.py      # baostock数据获取与本地缓存
├── factor_calc.py      # 量价因子计算
├── preprocess.py       # 去极值、标准化、方向统一
├── ic_analysis.py      # IC检验
├── backtest.py         # 回测与绩效评估
├── fundamental.py      # 基本面数据（EP、ROE）
├── valuation.py        # 估值因子
├── main.py             # 主运行脚本
├── plot_results.py     # 生成图表
├── requirements.txt
└── images/
    ├── nav_curve.png
    └── layered_bar.png
```

## 运行方式

```bash
pip install -r requirements.txt
python main.py
python plot_results.py
```

首次运行会通过 baostock 拉取数据并缓存到 `data/` 目录，后续运行直接读缓存。

## 已知局限

- 使用当前中证500成分股，存在幸存者偏差
- 未做行业中性化，多空组合可能存在行业暴露
- 季度调仓年化收益偏低，但换手率低、成本可控

## 后续改进方向

- 行业中性化，降低组合波动
- 加入低估值、高股息因子，适应风格切换
- 滚动窗口动态调整因子权重
