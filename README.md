# 中证500多因子选股策略研究与历史区间测试

## 项目概览
本项目基于中证500股票池，构建了从数据清洗、因子计算、交易账本记录到组合对照的完整量化研究流程。研究经历了从多空策略、纯多头策略到双组合物理合并的演进，并在新增的历史区间（2025Q4—2026Q3）对冻结策略进行了实证测试。

本项目重点展示**逐期账本核验、因子消融实验、组合对照**以及**对研究局限的客观披露**。**所有分析均在简化股票池假设下进行，结果定位为策略研究，不代表实盘承诺。**

## 核心结果

### 1. 历史开发期（2020Q2-2025Q3，共22期）
在多空策略遭遇重大回撤后，我们转为纯多头，并对不同因子组合进行了对照测试：

| 方案 | 累计净收益 | 季度年化夏普 | 季度采样最大回撤 |
| :--- | ---: | ---: | ---: |
| 等权基准 | 109.88% | 0.862 | -16.93% |
| 纯两因子 | 139.39% | 0.874 | -19.39% |
| 纯低波动 | 85.31% | 0.947 | -16.33% |
| **50/50组合** | **113.41%** | **0.982** | **-15.12%** |

### 2. 新增历史区间测试（2025Q4-2026Q3，共4期）
在冻结所有规则（因子窗口、选股比例、50/50合并比例）后，我们在未参与开发的新数据区间上进行了测试：

| 方案 | 4期累计净收益 | 季度年化夏普 | 季度采样最大回撤 |
| :--- | ---: | ---: | ---: |
| 等权基准 | -1.56% | -0.134 | -5.70% |
| 纯低波动 | -3.50% | -0.190 | -11.13% |
| **50/50组合** | **+3.90%** | **0.728** | **-1.33%** |

> **客观结论**：本区间 50/50 组合取得正收益，季度采样回撤小于两种对照，显示一定的组合互补效果；但仅有 4 期结果，不足以确认长期稳定性。

## 策略规则与计算口径（冻结版）

### 1. 股票池与筛选规则
- **数据源**：baostock，后复权日线。
- **股票池偏差**：**使用了当前中证500成分股回溯历史**（存在幸存者偏差风险），按代码排序截取前 300 只作为基础池。新增的2025Q4-2026Q3区间同样受此影响。
- **筛选**：剔除上市时间过短（历史不足 21 天）、停牌无数据及极端异常价格的股票，每期实际参与选股的股票数约 220~300 只。

### 2. 因子定义与子组合赋权
- **反转因子**：负的过去 20 日收益率（**越大越好**。严格使用第 -21 个交易日的收盘价至最新收盘价）。
- **均线比率**：`MA5 / MA20 - 1`（窗口 5 和 20，**越小越好**）。
- **低波动因子**：过去 60 个交易日日收益率的标准差 × √252（**越小越好**）。要求至少 61 个价格观测（产生 60 个收益率），若不足则赋予极大惩罚值（99.0），并在全截面进行百分位排名后取负，保证低波动股票获得高分。
- **标准化**：截面 MAD 去极值，排名百分位转换为 `[-0.5, 0.5]` 并统一方向（所有因子均转为越大越好）。
- **子组合构建**：
  - 两因子组合：`0.5 × 反转 + 0.5 × 均线比率` 评分前 25% 等权。
  - 低波动组合：低波动评分前 25% 等权。
- **50/50 合并规则**：重叠股票权重相加，`最终权重 = 0.5 × 两因子权重 + 0.5 × 低波动权重`。季度内权重随价格漂移，每次季度调仓时恢复 50/50。
- **行业约束**：无。

### 3. 交易执行与成本模型
- **买入规则**：T 日收盘产生信号，T+1 日以开盘价买入。
- **退出规则**：持有至**每季度最后一个交易日**，以当日收盘价进行盯市估值并退出。
- **停牌处理**：T+1 若停牌无法成交，资金留作现金；若买入后停牌，期末使用最后有效收盘价进行估值。
- **成本假设**：回测按**每季度全额买入并卖出（双边全额开平仓）**计费，单边统一成本为 **0.25%**（含佣金及假设的清算滑点），未按跨期持仓差额计算实际调仓交易。
- **换手率说明**：报告中提及的约 200% 换手，是指双边交易额与期初净值的比例（全额开平仓口径），并非跨期持仓的净变动。

### 4. 绩效指标
- **季度年化夏普**：使用季度净收益的样本标准差（`ddof=1`），假设无风险收益率为 0，年化因子为 `sqrt(4) = 2`。
- **季度采样最大回撤**：基于初始净值 1 及各季度末净值计算，**不覆盖季度内净值低点**。

## 交易账本验证（历史开发期）
本项目从零构建了 `Ledger` 类，负责记录每期每只股票的目标权重、实际成交价、收益率、费用及盈亏贡献。
- **验证范围**：基于原多空基线、22 期（2020Q2-2025Q3）的数据。
- **一致性保证**：原始账本记录 2958 条持仓，5916 笔开平仓交易。通过单元测试（`tests/test_ledger.py`，共 8 项测试）验证了开平仓日期/价格/金额与持仓匹配、金额随价格变化、费用单次计提，且账本汇总收益与原始回测逻辑收益一致。

## 2025Q3 尾部风险专题归因
2025Q3（2025-07-01 至 2025-09-30），原多空组合**毛收益约为 -31.63%**。亏损主要来自**空头持仓上涨造成集中亏损**：多头端贡献了约 +7.24 个百分点的正收益，而空头端贡献了约 -38.87 个百分点的亏损。
归因显示，亏损集中于制造业及部分中高动量股票；波动率分组未呈现明确单调关系。由于无法直接获取融券余额与成交量封板数据，**尚无直接证据表明发生了逼空**。详细归因过程见 `attribution_2025Q3.md`。

### 如何运行与数据说明
1. **数据快照（重要）**：报告结果依赖本地 `data/klines.pkl`。该快照**未随代码库一并提供**，需在首次运行时通过下方命令重新拉取。**由于数据修订及成分股名单变化，重新拉取并运行的结果可能与报告数值存在细微差异。** 原研究使用的成分股名单日期为 2026 年 9 月。
2. 环境安装：`pip install -r requirements.txt`
3. **更新数据（首次运行必做）**：
   ```bash
   python -c "from data_loader import load_all_data; load_all_data(force_refresh=True)"
   ```
4. 运行开发期对比（22期，生成 `experiments_dev/dev_summary.csv`）：
   ```bash
   python run_experiments_dev.py
   ```
5. 运行新增区间测试（4期，生成 `experiments_frozen_2025Q4_2026Q3/frozen_summary.csv`）：
   ```bash
   python run_frozen_test.py
   ```
6. 运行归因报告与单元测试：
   ```bash
   python run_attribution.py
   python -m pytest tests/ -v
   ```

## 已知局限
1. **数据幸存者偏差**：使用了当前中证500成分股回溯历史，未接入历史时点成分股名单。**2025Q4-2026Q3 区间同样受此影响，不构成严格样本外。**
2. **退出规则与边界**：回测严格采用自然季度最后一个交易日收盘估值并退出，期间不执行实际卖出。资金在季度末至下期建仓间假设为空仓。
3. **历史区间样本短**：4期观测的夏普估计不稳定，不足以证明长期有效性。
4. **日频净值未对齐**：当前最大回撤基于季度末净值采样。
5. **交易成本简化**：未按跨期持仓差额计算换手，实盘表现可能因摩擦成本而低于回测。
6. **代码版本记录**：本项目为本地研究快照。最新结果基于当前工作区代码（已推送至 GitHub），运行环境依赖本地数据快照及上述固定参数。
